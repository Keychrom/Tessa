最初に詰めるなら、01 Sumi。

現行の「青黒＋朱色」を残しながら、枠線と小ラベルを減らす案です。
色の馴染みやすさと、新しい情報階層を両立しやすいと考えます。

候補から、実装へ。

写真3点と手元のリポジトリを参照した提案です。HTMLは見た目と操作感の検討用で、Linuxパネル本体への反映は含みません。

01 / 情報を並べ直す

アプリ・ワークスペース・システムを分離。常時表示は最小限にし、細かな設定は右端から開く構成へ。CPU / MEM は Sumi・Paper・Signal で表示し、Orbit では省いて余白に振り替えます。

02 / 読めるサイズにする

主要ラベルは13–15px、補足は11–12pxを目安に。狭い画面では重要度の低いモジュールや長いウィンドウ名を既存のオーバーフローへ回す方針。HTMLは表示サイズを切り替えて比較できます。

03 / 実装範囲を分ける

高さ・位置・余白や配色は既存設定に対応。新しいランチャー配置と設定パネルの階層は描画・レイアウト・ヒット領域の改修が必要です。Orbit の独立した背景も追加の設計対象です。

確認した資料：添付のデスクトップ / ランチャー / コントロールパネル。リポジトリの README.ja.md、CUSTOMIZATION.ja.md、panel/draw.zig、panel/model.zig。
既存の bar_height（32–96）、bar_position、bar_top_margin、bar_side_margin とテーマの仕組みを前提にしています。ブラーに依存せず、不透明な面でも成立する見た目にしています。HTML内のウィンドウ・通知・メディアは架空のサンプルです。
