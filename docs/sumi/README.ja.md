# Sumi パネル実装

Sumi案を採用し、バー・ランチャー・コントロールセンターの外観と配置を変更しました。実装画面は [index.html](index.html) で確認できます。

## 外観と動作

- 高さ48pxのフラットなバー。標準では上端16px、左右20pxの余白。
- 墨色の面 `#1a2329`、生成りの文字 `#f0eee7`、珊瑚色のアクセント `#f08d72`。
- 中央配置のランチャー。基準サイズ620×620px。
- 標準の上部バーでは右寄せのコントロールセンター。
- 描画とクリック判定で共通の配置計算を使用。スクロール領域外の操作をクリップ。
- 画面が低い場合は内容をスクロールし、フッターは固定。
- 設定未指定時の既定値をSumiへ変更。既存の明示設定は維持されます。

## 変更ファイル

`panel/draw.zig`、`panel/model.zig`、`panel/main.zig`、`panel/sumi.zig`、
`config/panel.example`、`config/panel-sumi.conf`、
`tests/brightness.sh`、`tests/theme-editor.sh`、`tests/audio.sh`、`tests/sumi-panel.sh`。

`panel/sumi.zig` に色・寸法・配置計算と3件の配置テストをまとめています。
既存の操作テストは新しい画面配置に合わせ、`tests/sumi-panel.sh` を追加しました。

## 既存環境での適用

1. 更新したソースを通常の手順でビルド・インストールし、新しいパネルを起動します。
2. `~/.config/tessa/panel.conf` をバックアップします。
3. [Sumiプリセット](../../config/panel-sumi.conf) のキーを既存の `panel.conf` にマージします。同じキーは追記で重複させず、既存の値を置き換えてください。個人のコマンド・モジュール設定は残します。
4. `theme-colors.conf` は最後に読み込まれます。過去の色設定がSumiを上書きする場合は、バックアップを取って該当する色設定を調整してください。
5. `tessa-ctl config-check` で設定を確認し、`tessa-ctl dispatch reload` で再読み込みします。

設定の再読み込みだけでは実行中の古いバイナリは更新されません。プリセットの `Inter` が未導入の場合、利用可能なフォントによって見え方が変わります。

## 開発テスト

独立した Arch Linux 環境のテストコピーで実施しました。
常用セッションへのインストールや切り替えは行っていません。

実施済みの確認：
- ビルド成功、配置計算のテスト3件成功。
- ランチャー、コントロールセンター、設定再読み込み。
- 明るさ、テーマ変更とリセット、Wi-Fi接続、Bluetoothペアリング、音声操作の自動テスト。
- Sumi統合テスト：ワークスペース切り替え、検索とEnterによる起動、音量の両端と中間値、明るさ、電源プロファイル、集中モード、Wi-Fi・テーマ画面への移動。
- 1920×1080と1366×768で描画結果を確認。小さい画面でのスクロール、固定フッター、ランチャーも確認。

これらはヘッドレスの独立セッションと模擬システム・音声サービスによる確認です。
スクリーンショットはテストセッションで実際に描画された画面です。
実機の無線機器・音声機器・明るさ変更、物理キーボードのショートカットは未検証です。

ビルド済みのLinux環境での追加テスト：
```sh
zig test panel/sumi.zig
sh tests/sumi-panel.sh
```
統合テストに必要なツールはスクリプト先頭で確認します。
画像とログは既定で `sumi-artifacts/` に出力します。
`TESSA_SUMI_ARTIFACT_DIR` で出力先を変更できます。

## ソース反映の確認と復元

反映前に変更対象の元ファイルのSHA-256を作業開始時の値と照合しました。
検証済み10ファイルをコピーし、コピー後の一致を確認しています。
バックアップと変更前後のSHA-256は `delivery-manifest.json` に記録しました。
復元する場合は、現在の編集を保管したうえで、マニフェストのバックアップから既存ファイルを戻し、新規追加ファイルを個別に確認してください。
