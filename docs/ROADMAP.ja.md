# ロードマップ

Tessa は意図的に小さく保っています。ロードマップは「日本語で日常的に使える
デスクトップ」に必要なものから、その後の磨き込みへと並べています。

## 0.1.x — 土台を信頼できるものにする

- [ ] 対象マシンで DRM + libinput を実行し、レイアウトと入力の問題を直す。
- [ ] キーボードナビゲーションとマウス操作を一通りテストする（バーの
      クリック、右クリックで閉じる、フローティングのドラッグ/リサイズ、
      ランチャー入力）。
- [ ] フルスクリーン、クライアントポップアップ、クリップボード、複数
      ウィンドウのフォーカスを検証する。
- [ ] フローティング/リサイズ後の一時的な再描画漏れを修正する。
- [ ] headless コンポジタを起動してパネルの状態/IPC を検証する小さな
      統合テストを追加する。
- [x] ライセンスを決定する（MIT）。
- [ ] Arch/Ubuntu 向けにパッケージ化し、wlroots 0.19 を固定する。

## 0.2 — 入力とアプリケーション

- [x] `zwp_text_input_v3` + `input-method-v2` 対応（Fcitx5/Mozc）。入力
      ポップアップの配置とランチャーでの IME 入力を含む。
- [x] `xwayland-satellite` による XWayland。ディスプレイの自動選択、
      `DISPLAY` のエクスポート、xdg-decoration、headless 起動用の
      フォールバックキーボードを含む。
- [ ] layer-shell ポップアップの描画（サードパーティ layer クライアントの
      メニューなど）。
- [ ] 設定でのキーボードレイアウト/オプション対応（現在は `XKB_DEFAULT_*`
      を使用）。
- [ ] タッチパッドジェスチャ（ワークスペーススワイプ、ランチャー
      ジェスチャ）。
- [ ] タッチとタブレットの対応。
- [ ] ゲーム向けの pointer constraints / relative pointer。
- [x] primary selection（`wlr_primary_selection_v1`）。
- [ ] X11 アプリケーション向けの XIM 統合。

## 0.3 — シェルとデスクトップ統合

- [ ] すべての出力にバーを表示し、出力ごとのアクティブワークスペースを
      持つ。
- [ ] トレイ / StatusNotifier、メディア操作、バッテリー、ネットワーク、
      オーディオ。
- [ ] カレンダー/時計ポップアップ。
- [ ] 電源メニューとセッションロック（`ext-session-lock-v1`）。
- [ ] idle-inhibit と DPMS。
- [ ] スクリーンショット UI と `xdg-desktop-portal` 連携、PipeWire による
      画面共有。
- [ ] 通知デーモンの統合。
- [ ] クリップボード履歴。

## 0.4 — 見た目とレイアウトの深化

- [ ] ウィンドウの開閉/ワークスペース切り替えアニメーション（任意。
      視差効果を減らす設定も用意）。
- [ ] 独自の wlroots シェーダーによる角丸とブラー。
- [ ] 適切なドロップシャドウ。
- [ ] バーの高さ、マージン、フォント、パレット、壁紙アートの
      テーマ/設定。
- [ ] より多くのタイルレイアウトと、ワークスペースごとのレイアウト
      プロファイル。
- [ ] モザイクレイアウトの最小サイズ処理とキーボードリサイズ。
- [ ] HiDPI/スケールと出力モードの設定。
- [ ] マルチモニタでのワークスペース固定。

## 1.0 — 安定性

- [ ] 分かりやすいエラーを伴う設定バリデーション。
- [ ] IPC のスキーマ/バージョニングと、外部ツール向け JSON オプション。
- [ ] 設定と IPC パーサーの Fuzzing / ASan 実行。
- [ ] パネルのクラッシュ復旧。
- [ ] 完全なユーザーガイドとテーマガイドのドキュメント。
- [ ] 再現可能なパッケージとリリースプロセス。

## 非目標

- TypeScript/JS による設定ランタイムやプラグイン VM。それは ShojiWM の
  方が得意です。
- Hyprland のすべてのエフェクト/プラグインを追いかけること。Tessa は
  エフェクトの寄せ集めではなく、一貫した静かなデスクトップであり続けます。
- 内蔵ターミナル。kitty/foot の方が急いで作ったターミナルより優れており、
  ターミナルを外部に任せることは最初から許容されています。
